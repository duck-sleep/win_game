# HapticX 使用说明

> 动态触觉反馈:Chrome 放歌,手柄跟着震。对标雷云4 SENSA"音效转触觉"。

## 快速开始

双击 **`启动HapticX.bat`**(推荐,无黑窗口)。

或命令行:
```
%LOCALAPPDATA%\Programs\Python\Python313\python.exe -B D:\win_game_project\25_xbox_control\hapticx\app.py
```

命令行原型(无界面):
```
python main.py --test-vib 1     # 马达自检
python main.py --verbose        # 均衡模式跑链路,终端实时能量条
python main.py --mode dynamic   # 动态模式
python main.py --probe          # 雷云日志侦察
```
(命令行原型用 PATH 里的 python 也行;GUI 必须用上面完整版 Python,因为 TRAE 自带的精简 python 没有 tkinter)

## 界面操作

| 位置 | 功能 |
|------|------|
| 左侧栏 | 仪表板/触觉反馈/设备/设置,底部显示手柄型号和连接状态 |
| 触觉反馈页·总开关 | 右上角绿色开关,振动总闸 |
| 强度 | 全局增益 0.05-1.5(默认 0.67,雷云真值) |
| 触觉源 | 两张卡片(对标雷云 Haptic Source):音效转触觉=本程序,Sensa HD 游戏=置灰需游戏支持;音频输入下拉选输出设备 |
| 档位 | 四张卡片(对标雷云 AUDIO-TO-HAPTICS PROFILE):受控/均衡/动态/自订,选中绿框 |
| 频段增益 | 图形化拖拽编辑器,超低音/低音/中低音三柱,百分比显示,每个档位一条独立曲线并随切换联动 |
| 实时频谱 | 16 频段柱,绿色=30-130Hz 触觉频段,BEAT 灯=节拍脉冲 |
| 马达电平条 | 左马达(低频)/右马达(高频+节拍)实时输出 |
| 设备页 | 雷云日志挖出的完整情报(型号/A2H配方/编码器DLL) |
| 设置页 | 自订模式 6 参数滑条 + 保存配置 |

## 使用前注意

1. **雷云4 可以开着,但要在雷云里关闭 SENSA 动态触觉开关**(否则两边抢马达,互相打断)
2. 手柄必须在 **Xbox 模式**(2.4G 接收器或有线),PC/DirectInput 模式 XInput 认不到
3. 插拔耳机/换默认输出设备,程序每 2 秒自动检测并重建捕获,不用重启

## 环境说明

- 完整 Python 3.13.9 装在 `%LOCALAPPDATA%\Programs\Python\Python313`(仅当前用户,已带 tkinter)
- 依赖:SoundCard、numpy、psutil(已装齐)
- 配置保存在 `hapticx\config.json`(模式/强度/自订参数/设备选择,关窗自动保存)
- 本机 PATH 里的 `python` 是 TRAE 精简版(无 tkinter),所以 GUI 用 bat 里指定的完整版

## 常见问题

| 现象 | 原因/解决 |
|------|----------|
| 手柄不震 | 检查 Xbox 模式;`main.py --test-vib 1` 自检;总开关是否打开 |
| 振动被抢/怪 | 雷云里关掉 SENSA 动态触觉 |
| 没声音不震 | 正常,静音门限 0.03;确认输出设备选对了 |
| 震太弱/太强 | 调"强度"滑条,或换"动态"模式 |
| 节拍没脉冲 | 只有动态/自订模式有节拍脉冲,均衡是雷云默认平滑行为 |
