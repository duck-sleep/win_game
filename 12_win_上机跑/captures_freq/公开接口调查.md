# 公开 Interhaptics / Wyvrn 接口调查（W0.5 / W0.6）

## 官方明确（文档）

| 项 | 结论 | 来源 |
|----|------|------|
| `.haps` 可编辑 amplitude 与 frequency/pitch | 是 | [Wyvrn .haps 格式](https://doc.wyvrn.com/docs/interhaptics-sdk/haptic-composer/haps-file-format/) |
| `AddParametricEffect(amplitude, pitch, freqMin, freqMax, transient…)` | 是 | [Engine Control](https://doc.wyvrn.com/docs/interhaptics-sdk/haptics-sdk-for-game-engines/engine-control/) |
| Haptic Composer 支持在设备上测试，含 **Razer Sensa HD** | 文档列出 | [Haptic Composer](https://doc.wyvrn.com/docs/interhaptics-sdk/haptic-composer/) |
| pitch 为 0–1，映射到 freqMin–freqMax（Hz） | 是 | Engine Control / Unity API Usage |

换算（工单统一）：

```
pitch_norm = clamp((f_hz - freqMin) / (freqMax - freqMin), 0, 1)
```

本机 A2H 快照建议优先用 **output_frequency_range 30–80 Hz**（见 `雷云马达能力.md`）。

### 闸门（W3A.4）

**公开 pitch 直控：结果模糊**

正门函数能调、设备被 GameInput 枚举到 1 台，但 **Sensa HD 提供器不认这只 0a4c Wolverine**。因此不能说「官方 HD pitch 已经打到马达」。GameInput 通道在 Xbox 360 人格上通常只有左右震动强弱，没有独立 Hz。未开 USB 抓包（等用户点名 W3B）。
