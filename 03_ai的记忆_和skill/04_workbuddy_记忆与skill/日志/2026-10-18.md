## 10-18 续（本会话）：T1–T4 闭环
- **T1**：COM15 装 `serial-getty@ttyGS0` autologin drop-in → `active`；Windows 侧 COM15@115200 `whoami;tty` = `kickpi`/`/dev/ttyGS0`。坑：`kickpi` 不在 `dialout` 组，但 agetty 以 root 开 tty 后交权，shell 读写正常，不用加组。
- **T2**：连 `Duck_5G`（密码 8 个 0）→ `192.168.31.89/24`，SSH enable+active；重启后 WiFi 自动连，但 IP 先拿 `.90`、续租 `.89` 回来，网卡双挂两个地址（ARP 都指板子 MAC）。**用户拍板：不绑 MAC、不写静态 IP —— AI 侧 SSH 走 `kickpi.local`（avahi 正常），手机侧每次用当时查到的 IP。**
- **T3**：Windows 公钥进板 `authorized_keys`；`~/.ssh/config` 加 `Host k11c → kickpi.local`；`/opt/k11c-kvm` 属主 kickpi；scp md5 两边一致。坑：Git Bash 下 scp 目标要先 `export MSYS_NO_PATHCONV=1`。
- **T4**：`board/fakesrc.sh` + `board/kvm_server.py` 上板跑通：fps 30.0、JPEG 1280x720、两帧 md5 不同、Windows 拉图肉眼确认彩条+码表 `00:03:04.567`、多客户端共享最新帧。坑：`ssh k11c '... & ...'` 起后台服务时 ssh 会话不返回（后台进程占通道），要 `setsid nohup ... </dev/null &` 且别在同一会话等它。
- **数据**：ffmpeg 720p30 MJPEG 软编吃 **166.7% CPU**（4 核 A55 的 1.67 核）；`/state` 在 Windows 侧 39 ms 拿到一张 snapshot。若 T5/T7 挤不动，候选优化是换 `mppjpegenc` 硬编（本轮先不动，按文档走）。

## 10-18 续（本会话）：T6 闭环，中间踩了一个固件级 bug
- **T6 四条全过**：鼠标 16384,16384 → 光标 **960,540**；`typeText "Hello K11C 123!"` + Ctrl+A/C → 剪贴板**逐字相等**；`wheelReport y:-5` → 记事本从 line 1 顶格滚到 line 16 顶格（3 行/格 × 5，两张截图肉眼确认）；300 次串行 **3.086 s**、0 错误、之后 ping 照回。
- **卡最久的是固件级 bug**：重启后 Windows 变"无法识别的设备"、UDC 停 `addressed`，换口 + 重启电脑 + 重启板子都没用。真因是镜像里 `/usr/local/sbin/k11c-gadget.sh` 是**旧版**（`cat|tr > serialnumber || 兜底` 写进空串 → 主机读字符串描述符失败）。10-17 手改的是运行态，一重启就被旧脚本重建。同步源头版 `31743bd6` 后立刻 `configured`。**下次出固件必须带上这个脚本**。
- **服务托管**：`setsid nohup` 起的服务会被 logind 连 ssh 会话一起杀掉 → 改 `systemd-run --unit=k11c-kvm-run --collect`（`board/run.sh`）。另外 root 也追加不了 kickpi 的旧文件（sudo 缺 CAP_DAC_OVERRIDE）。
- **写 HID 必须有界重试**：HID IN 队列只有 1 深，"按下+松开"连着发第二枪必 EAGAIN；不重试时 `typeText` 直接报 `-32001`。现在 20×5ms 重试 + `TCP_NODELAY`。
- **测量口径**：`Invoke-RestMethod` 单次 55–62ms、`kickpi.local` 298ms（先试 IPv6 link-local）、raw socket 打 IP 才 12–19ms；板子 WiFi 侧 ping 只有 3ms，笔记本网卡 **Power Saving Mode=开启** 才是抖动来源。以后量延迟一律 raw socket + IP。
- **测试脚本两个坑**：`Start-Process notepad` 在这台机器上弹"你要如何打开这个文件"（键鼠一度打进该对话框，已 Esc 关掉、确认没误启动程序）；`.ps1` 被 PS5.1 按 GBK 读，带中文就语法报错 → 测试脚本只写 ASCII。
- **T5 挂起**：用户暂时没有电视（"下次搞一台"），电视输出这条等硬件。ACM 口从 COM15 变成 **COM16**。
