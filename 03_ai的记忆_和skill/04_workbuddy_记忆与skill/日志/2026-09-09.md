## 诊断 AI 回答慢 / WebSocket 10054（16:40）

- 现象：WorkBuddy 报错 `WebSocket error: ... Os code 10054 ConnectionReset ... https://tokenrhythm.studio/v1/chat/completions (HTTP 500) (4028)`，回答明显变慢。
- 结论：**不是本机网络问题，是服务端限流/过载**。
- 证据链：
  1. DNS 正常 `tokenrhythm.studio` → CNAME `alb-djvadghu26ruqsl9av.cn-beijing.alb.aliyuncsslb.com` → **8.152.204.11 / 47.94.77.190**（阿里云北京 ALB，国内节点）
  2. 直连 TLS 握手 0.53s、走沙箱代理 0.18s，两个后端 IP 单独测都能建立 TLS 并响应 → 链路无问题
  3. **10 次抽样：2 次 401、8 次 429 Too Many Requests**，其中含 10.3s / 6.3s 超慢响应 → 服务端在限流排队
  4. 429 响应头带 `x-trace-id`，CSP 含 alicdn/阿里云 captcha 域名 → 确认阿里云北京部署
- 环境侧排查：本机代理变量 `http_proxy=127.0.0.1:3796` = **sandbox-cli.exe（WorkBuddy 自带沙箱代理），不是 Clash**；FlClash 只有 HelperService 在跑，无 TUN 虚拟网卡 → 当前流量直连国内，无劫持。
- 给用户建议：① 限流窗口等几分钟重试 ② 别连续重试（越点越限）③ 该域名是国内 IP，**开 FlClash TUN/全局时务必给它加直连规则**，绕境外会更慢更易断（尤其人在香港时）。

- 后续：确认 `tokenrhythm.studio` = **基源律动**（WorkBuddy 当前模型服务）。本地 `~/.workbuddy` 内无该端点的明文配置（只在 traces 里出现），**端点由服务端下发，本机改不了**，换模型只能看 UI 有没有切换项。
- 诚实修正：429 有相当一部分是我连续压测（20+ 次）自己打出来的；但用户遇到的 500 + 10054 发生在探测之前，服务端不稳这个结论成立。
- 固化 skill：`skills\api-endpoint-slow-diagnosis\SKILL.md`（五步法：DNS 定性 → 分层计时 → 逐后端 IP → 抽样统计 → 排查代理劫持，含错误码判读表和自限流警告）。

## WiFi 慢 / 热点快 根因定位（19:20~19:50）

- 现象：用户反馈"用手机热点连模型很快，用家里 WiFi 就不行"。
- **根因：电脑连在 2.4GHz 信道 1（802.11n）上，而网卡 Intel Wi-Fi 6 AX201 支持 5GHz/ac/ax。**
  - SSID `Duck`，信号 98% 但接收速率仅 78 Mbps（Wi-Fi 6 在 5G 下应数百 Mbps）→ 典型 2.4G 干扰特征
  - 网关 ping 平均从 7ms 波动到 24ms → 无线侧抖动
  - 路由器只广播 1 个 BSSID（信道 1），未见 5G 频段 → 疑似 5G 未开启/被隐藏
- 排除项（证据）：
  - 网关/阿里DNS/腾讯DNS/百度 全部 **0% 丢包** → WiFi 无线侧不是宽带链路问题
  - 到阿里云北京两 IP ping 丢 12%，但 **TCP 连接稳定 46~78ms、首字节 110~200ms 不抖动** → **ICMP 丢包是阿里云 ALB 限速的假象，TCP 层没丢**
  - 长连接空闲 15s/30s 均存活（45s 那次偶发死，非固定阈值）；对照百度腾讯 45s 也存活 → **双层 NAT（192.168.31.1→192.168.50.1）不是凶手**
  - 5 次 HTTPS 采样全 401，无 429 → 此时段服务端未限流
- 输出物（均在 `23_网络诊断\`）：
  - `netcheck.py` —— 一键体检（出口IP、本地链路、目标丢包、分层计时、长连接存活、自动结论），支持 `python netcheck.py wifi|hotspot` 打标签并存报告
  - `idle_conn_test.py` —— 长连接空闲存活测试（可换 host 做对照）
  - `netcheck_wifi_0909_1945.txt` —— WiFi 基线报告
- skill 更新 `api-endpoint-slow-diagnosis`：新增**第 0 步 最后一公里（无线侧）**（2.4G/5G/信道/信号vs速率判据表，含"信号满格≠健康"）、"两个已验证假象"（云厂商限速 ICMP、Python ssl 握手假慢 2.3s）、长连接空闲测试必须带对照。
